React 18 NestJS Supabase Google Places API

Idea

Cílový uživatel: cestovatel mladší generace, který chce přehledně naplánovaná místa v dané destinaci — bez žonglování se zápisníky a tabulkami.

  1. Uživatel zadá destinaci + termín
  2. Aplikace vygeneruje strukturu dnů
  3. Volitelně: AI sestaví kostru itineráře
  4. Uživatel přidává místa, řadí je, označuje jako navštívená
  5. Sdílení anonymním odkazem (read-only, jako Google Drive)

API třetích stran

Služba Účel Popis
OpenAI Generování itineráře (AI) Bearer token (`OPENAI_API_KEY`)
Google Places API Vyhledávání míst, autocomplete, fotky, detaily POI API key (`GOOGLE_PLACES_API_KEY`)
*Google Maps JS API Interaktivní mapa v UI (fullscreen, piny, klikání na POI) API key (`VITE_GOOGLE_MAPS_KEY`)
Supabase PostgreSQL databáze + Auth (Google OAuth, JWT) API key (`VITE_GOOGLE_MAPS_KEY`)
yr.no (MET NORWAY) Předpověď počasí pro termín cesty (do 9 dní) User-Agent header
Open-Meteo Historická data počasí (stejné datum, minulý rok) – fallback pro delší cesty bez autentizace

Top Challenges

🔐 Invite-only prostředí
Cílem bylo rychlé spuštění aplikace, ale pouze pro "zvané uživatele".
❌ Pozastavení projektu ze strany Supabase
Pokud je projekt delší dobu nečinný, tak Supabase pozastaví přístup k databázi.
🌦️ Předpověď počasí
Bylo třeba vyřešit, jakým způsobem brát data o počasí (historický průměr nebo aktuální předpověď) a jak tato data průměrovat (nejvyšší denní teplota, průměrná denní teplota atd...)
🪵 Logování Google Places
Google Places API účtuje dle SKU — každý typ volání má jinou cenu. Bylo třeba sledovat reálné náklady per uživatel bez dopadu na výkon.

Interesting Facts

🗺️ Mapa jako primární UI
Google Maps fullscreen, itinerář je sekundární vrstva (strip karet dole na mobilu)
📍 Klik na nativní Google POI
Přímo přidá místo do itineráře — bez hledání
🔁 Duplicita míst
Detekována přes googlePlaceId — aplikace se zeptá před přidáním podruhé
💰 Admin cost dashboard
Náklady Google Places (dle SKU) i OpenAI tokenů + e-mail uživatele pro audit
🔗 Share link bez přihlášení
Stejný pattern jako Google Drive — jen odkaz, žádná registrace

Future Vision

🌐 Obsah od komunity
Uživatelé sdílejí itineráře veřejně — ostatní je mohou procházet, kopírovat a inspirovat se
📶 Offline mode
Service Worker + lokální cache — itinerář dostupný bez internetu přímo v zahraničí
💬 Chatbot pro přidávání míst
Uživatel popíše co chce a chatbot místa navrhne a přidá přímo do itineráře
💳 Kreditový model
Monetizace přes kredity — AI generování a pokročilé funkce čerpají kredit, základní plánování zdarma
👥 Kolaborativní plánování
Více uživatelů edituje cestu v reálném čase (WebSocket / CRDT)
🌍 Multi-destinační cesty
Datový model připraven — destinations JSONB, migrace 004
