03

Dědičnost

Nastavíš vlastnost na rodič → zdědí všichni potomci. Potomek může přepsat jen to, co chce změnit.

/* Základ pro celou prezentaci */
.reveal {
  font-family: 'Lato', sans-serif;
  color: #1e1c18;      ← zdědí vše
  background: #f7f4ef;
}

/* Nadpisy zdědí color, ale přepíší font */
.reveal h1, .reveal h2 {
  font-family: 'Lora', serif; ← přepsáno
  /* color se zdědí z .reveal */
}

/* Konkrétní prvek přepíše jen barvu */
.reveal h3 {
  color: #2563a8;         ← přepsáno
}

Co se dědí automaticky

color · font-family · font-size · line-height · text-align

Co se NEDĚDÍ

background · border · padding · margin · width / height

Tyto vlastnosti musíš nastavit každému prvku zvlášť.

Kaskáda – kdo vyhraje?

/* Čím specifičtější, tím silnější */
h2         { color: gray;  }  0,0,1
.box h2    { color: blue;  }  0,1,1 ✓
#main h2   { color: green; }  1,0,1 ✓✓

/* Poslední záchrana – přebije vše */
.reveal h2 { color: red !important; }

!important používej jen jako krajní řešení.

04

CSS proměnné

Definuješ barvy a fonty jednou v :root – změna na jednom místě aktualizuje vše.

/* Definice v :root (kořen stránky) */
:root {
  --barva-ink:    #1e1c18;
  --barva-akcent: #2563a8;
  --font-text:    'Lato', sans-serif;
  --font-nadpis:  'Lora', serif;
}

/* Použití kdekoliv přes var() */
.reveal {
  font-family: var(--font-text);
  color:       var(--barva-ink);
}
.reveal h1 {
  font-family: var(--font-nadpis);
}
.zvyrazneni {
  border-color: var(--barva-akcent);
  color:        var(--barva-akcent);
}

Bez proměnných

h1    { color: #2563a8; }
.btn  { color: #2563a8; }
.box  { border: 1px solid #2563a8; }

/* Změna barvy = najít+nahradit na 3 místech */

S proměnnými

:root { --akcent: #2563a8; }
h1    { color: var(--akcent); }
.btn  { color: var(--akcent); }
.box  { border: 1px solid var(--akcent); }

/* Změna = 1 řádek v :root ✓ */

Tip: Název začíná vždy -- (dvě pomlčky). Hodnotu čteš přes var(--nazev).

05

em vs rem

Oba jsou relativní jednotky – ale relativní vůči čemu se liší.

rem – relativní vůči :root

:root { font-size: 17px; } ← základ

h1  { font-size: 3rem;    } = 51px
h2  { font-size: 2rem;    } = 34px
p   { font-size: 1rem;    } = 17px
nav { font-size: 0.85rem; } = 14px

/* rem je vždy předvídatelný */

Vždy 17px × hodnota – bez ohledu na kontext.

em – relativní vůči rodiči

.box  { font-size: 1.2em; } = 20px
.box p{ font-size: 0.9em; } = 18px (od .box!)

/* em se vrství – může překvapit */
.a { font-size: 1.2em; }  1.2 × 17 = 20px
.a .b { font-size: 1.2em; } 1.2 × 20 = 24px!

Hodí se pro padding a margin uvnitř komponent.

Kdy co použít

Co stylujuJednotka
Velikost písma (globálně)rem ✓
Padding uvnitř tlačítkaem – škáluje s textem
Margin mezi blokyrem ✓
Šířka/výška prvkůrem nebo %
Border, border-radiuspx nebo rem

Praxe v Reveal.js

:root { font-size: 17px; }

.reveal h2 { font-size: 1.9rem; }
.reveal p  { font-size: 0.95rem; }

/* Padding tlačítka škáluje s fontem */
.btn { padding: 0.4em 1em; }
.btn-lg { font-size: 1.1rem; }
/* padding se zvětší automaticky ✓ */

Boxy – komponenty

Sdílený základ .box, každá varianta přidává jen svůj rozdíl.

/* Základ – sdílené vlastnosti */
.box {
  padding: 1rem 1.2rem;
  border-radius: 5px;
  margin: 0.5rem 0;
}

/* Varianty přidají jen svůj styl */
.box-blue {
  background: #eff6ff;
  border-left: 3px solid #2563a8;
}
.box-amber {
  background: #fffbeb;
  border-left: 3px solid #b45309;
}
.box-filled {
  background: #1e1c18;
  color: #f7f4ef;
}

/* HTML: kombinuješ volně */
<div class="box box-blue">Info</div>
<div class="box box-amber">Pozor</div>

Výsledek

box-blue – informace, tipy
box-green – správně, úspěch
box-amber – upozornění
box-red – chyba, varování
box-plain – neutrální obsah
box-filled – důraz, tmavý

Sourozenci: + a ~

Výběr prvků na stejné úrovni – ne potomků, ale sousedů.

A + B  hned za

/* Jen PRVNÍ p hned za h5 */
h5 + p { color: blue; font-weight: 600; }

<h5>Nadpis</h5>
<p>Modrý ✓</p>     ← hned za h5
<p>Šedý ✗</p>      ← druhý, nefunguje
<p>Šedý ✗</p>
Nadpis sekce

✓ modrý – hned za h5

✗ šedý – druhý odstavec

✗ šedý – třetí odstavec

<h5>Nadpis</h5>
<p>Zelený ✓</p>
<p>Zelený ✓</p>
<p>Zelený ✓</p>

✗ šedý – před h5

✓ zelený

Více tříd .a.b bez mezery

Prvek s oběma třídami zároveň. Základ pro komponentové CSS.

/* Základ – sdílené vlastnosti */
.btn {
  display: inline-block;
  padding: 0.4em 1em;
  border-radius: 4px;
}

/* Varianta – styl */
.btn-outline { border: 1px solid gray; }
.btn-blue    { background: blue; color: white; }
.btn-red     { background: red;  color: white; }

/* Varianta – velikost */
.btn-lg      { font-size: 1.1rem; }

/* Kombinace obou variant (bez mezery!) */
.btn-blue.btn-lg { font-weight: 700; }

/* HTML – kombinuješ volně */
<button class="btn btn-outline">Outline</button>
<button class="btn btn-blue btn-lg">Velký</button>

Výsledek

Outline Solid
Blue Red
Blue Large
Red Large

⚠ Pozor na mezeru!

.btn.btn-blue – prvek s oběma třídami
.btn .btn-blue – btn-blue uvnitř btn
Je to úplně jiný selektor!

Kdy použít

Tlačítka, kartičky, tagy, ikony – kdekoliv máš základní komponentu s variantami.

13

Pseudotřídy :

Vybírají prvky podle stavu nebo pozice v dokumentu.

Stav prvku

a:hover          { background: blue; }
a:focus          { outline: 2px solid blue; }
a:active         { opacity: 0.7; }

input:disabled   { opacity: 0.4; }
input:focus      { border-color: blue; }

Pozice v DOM

li:first-child   { color: gold; }
li:last-child    { color: gray; }
li:nth-child(2)  { color: green; }
li:nth-child(odd)  { background: #f0f0f0; }
li:nth-child(even) { background: white; }

/* Vzorce */
li:nth-child(2n)   ← každý sudý
li:nth-child(3n)   ← každý 3.
li:nth-child(n+4)  ← od 4. dál

Živá ukázka – nth-child

  • první – zlatý (first-child)
  • druhý – zelený (nth-child(2))
  • třetí – normální (lichý → světlý bg)
  • čtvrtý – normální (sudý → bílý bg)
  • pátý – normální (lichý)
  • poslední – šedý (last-child)

Tip pro Reveal.js

/* Každý druhý snímek jiné pozadí */
.reveal section:nth-child(even) {
  background: #edeae3;
}

/* První snímek bez paddingu */
.reveal section:first-child {
  padding: 0;
}
14

Negace :not()

Vybere vše kromě prvků, které napíšeš do závorky.

/* Vše kromě .disabled */
.card:not(.disabled) {
  border-left: 3px solid green;
}

/* Každé li kromě posledního */
li:not(:last-child) {
  border-bottom: 1px solid #ddd;
}

/* Input, ale ne submit tlačítko */
input:not([type="submit"]) {
  border: 1px solid gray;
}

/* Lze kombinovat více podmínek */
.box:not(.box-filled):not(.box-red) {
  opacity: 0.9;
}

/* V Reveal.js – vše kromě titulního */
.reveal section:not(.slide-title) h2 {
  border-bottom: 1px solid #ddd;
}

Živá ukázka

✓ normální karta
✓ normální karta
✗ disabled karta
✓ normální karta
✗ disabled karta

:not() vs. přepisování

/* Bez :not – musíš přepsat */
.card          { border-left: 3px solid green; }
.card.disabled { border-left: 3px solid red; }

/* S :not – čistší záměr */
.card:not(.disabled) { border-left: 3px solid green; }
.card.disabled        { border-left: 3px solid red; }
15

Atributové selektory [ ]

Vybírají prvky podle hodnoty HTML atributů.

/* Má vůbec atribut href? */
a[href]              { color: blue; }

/* Přesná hodnota */
input[type="text"]   { border: 1px solid gray; }
input[type="submit"] { background: blue; }

/* ^ začíná na */
a[href^="https"]  { color: green; }
a[href^="http:"]  { color: red; }

/* $ končí na */
a[href$=".pdf"]   { color: orange; }
a[href$=".zip"]   { color: purple; }

/* * obsahuje kdekoliv */
a[href*="github"] { font-weight: bold; }

Živá ukázka

https odkaz (zelený ↗) http odkaz (červený) PDF soubor (zlatý) ZIP archiv

Přehled operátorů

OperátorPodmínka
[attr]atribut vůbec existuje
[attr="x"]rovná se přesně
[attr^="x"]začíná na x
[attr$="x"]končí na x
[attr*="x"]obsahuje x kdekoliv

Pseudoelementy ::before a ::after

Vkládají obsah do stránky přes CSS, bez zásahu do HTML.

/* Povinné: content musí být vždy! */
h2::before {
  content: "";           ← prázdný = dekorace
  display: block;
  width: 2rem;
  height: 3px;
  background: blue;
  margin-bottom: 0.5rem;
}

/* Ikonka/label za odkazem */
a[href$=".pdf"]::after {
  content: " PDF";
  font-size: 0.7em;
  background: orange;
  padding: 0.1em 0.4em;
  border-radius: 3px;
}

/* Automatické číslování */
.seznam { counter-reset: kroky; }
.krok   { counter-increment: kroky; }
.krok::before {
  content: counter(kroky) ". ";
  color: blue;
  font-weight: 700;
}

Specifičnost – kdo vyhraje?

Když dva selektory míří na stejný prvek, zvítězí ten specifičtější.

/* Skóre: (ID, třídy, tagy) */

p               ← (0, 0, 1)
.box            ← (0, 1, 0)
.box p          ← (0, 1, 1)
#hlavni         ← (1, 0, 0)
#hlavni .box p  ← (1, 1, 1)

/* Příklad konfliktu */
p      { color: gray;  }  (0,0,1)
.text  { color: green; }  (0,1,0) ← vyhraje
#main  { color: blue;  }  (1,0,0) ← vždy vyhraje

/* Reveal.js – framework má vysoké skóre */
h2          { color: red; }  ← pravděpodobně prohraje
.reveal h2  { color: red; }  ← vyhraje ✓

Praktická pravidla

  • Vždy začínej selektory s .reveal
  • Vyhni se #id v CSS – jsou příliš silné
  • !important je poslední záchrana, ne zvyk
  • Čím kratší selektor, tím snáze se ladí

Celková struktura CSS souboru

Doporučené pořadí – od obecného ke konkrétnímu

/* 1. PROMĚNNÉ – paleta, fonty */
:root {
  --bg: #f7f4ef;  --ink: #1e1c18;
  --akcent: #2563a8;
}

/* 2. DĚDIČNOST – základ pro vše */
.reveal { font-family: var(--font); }
.reveal h1, h2 { font-family: var(--nadpis); }

/* 3. LAYOUT – grid systém */
.cols-2 { display: grid; grid-template-columns: 1fr 1fr; }
.cols-3 { display: grid; grid-template-columns: 1fr 1fr 1fr; }

/* 4. KOMPONENTY – znovupoužitelné prvky */
.box       { padding: 1rem; border-radius: 5px; }
.box-blue  { border-left: 3px solid var(--akcent); }

/* 5. UTILITY – pomocné třídy */
.mt   { margin-top: 1rem; }
.tc   { text-align: center; }
.muted { color: gray; font-size: 0.85rem; }
